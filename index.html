Before you start

  • Wet the two electrode areas on the strap and wear it snug. The H10 only wakes up on skin contact.
  • Close other apps that are streaming from the strap (Polar Flow syncing in the background is fine).
  • ECG streaming needs H10 firmware 3.0.35 or later. Update it in Polar Flow if the connection works but no trace appears.
  • Keep this tab in front while recording. The page asks the screen to stay on. Data lives in memory until you download it (roughly 25 MB of CSV per hour).
  • If the strap drops out, the page reconnects by itself and keeps recording. Any gap shows up in the timestamps.
  • If Connect reports that Bluetooth isn’t allowed, open Terminal in the folder with this file, run python3 -m http.server 8000, and visit http://localhost:8000/.

What’s in the files

polar-h10-ecg-….csv
One row per sample (130 per second): elapsed_s from the first sample on the sensor clock, unix_time_ms wall-clock time anchored to this computer, sensor_timestamp_ns from the H10, ecg_uV raw value in microvolts (divide by 1000 for mV), and marker (M1, M2 … where you pressed Add marker).
polar-h10-hr-rr-….csv
unix_time_ms, hr_bpm and rr_ms as reported by the strap, one row per R–R interval. Useful for HRV tools such as Kubios.
The H10 is a consumer sensor, not a medical device. Nothing is uploaded: the recording stays in this browser until you download it.
